# Climate Change Application
This Flutter application is part of the CMM311 Digital Media for Learning and CMM322 Smart Device Application Development project at King Mongkut’s University of Technology Thonburi.

The app is designed to educate users about climate change through interactive learning modules, engaging minigames, and quizzes. Users can explore various topics, test their knowledge, and track their progress as they learn about the causes, effects, and solutions to climate change.

## Preview
You can preview the app here: [https://hugekc01.github.io/flutter_studyclimatechage_web/]

## Features
- Interactive learning modules about climate change
- Minigames to reinforce learning
- Quizzes to test knowledge
